# Model status

The game uses reduced-order equations designed to make the archived project behavior interactive.

Numerical archive values are not automatically physical validation. In particular:
- control derivatives are parametric;
- orthotropic material values are a surrogate envelope;
- chemistry is not enabled in the game loop;
- shock stand-off is a reduced visualization variable;
- the front rotor concept is not represented as a proven drag-reduction device.

The game intentionally avoids modeling destructive electrode energy matching or weapon optimization.
